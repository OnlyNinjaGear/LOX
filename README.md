# LOX

[Играть в демо](https://onlyninjagear.github.io/LOX/)

Мобильный тренажёр взлома замков по мотивам Gothic Remake. Случайные решаемые замки, связанные пластины, свайпы, звуки и поломка отмычки.

## Запуск

Никакой сборки или зависимостей:

```sh
python3 -m http.server 8080
```

Откройте `http://localhost:8080/`. Для размещения на хостинге загрузите `index.html`, `guide.html`, `style.css`, `app.js`, `sound.js` и папку `mechanics` в одну директорию. Открывайте через HTTP(S), не через `file://`.

Демо автоматически обновляется через GitHub Pages при изменениях в `main`. Для своей копии: **Settings → Pages → Deploy from a branch → main → / (root)**. Отдельная сборка не нужна.

## Управление

- Свайп по пластине: один шаг в сторону свайпа.
- Касание: выбор пластины. Нижние стрелки: движение выбранной.
- Клавиатура: ↑ ↓ выбирают, ← → двигают, пробел создаёт новый замок.
- «Меню»: новый сундук, количество пластин, звук и поломки.
- Первая ошибка повреждает отмычку, вторая ломает и возвращает замок к началу.

Пластины с отверстиями двигаются под неподвижными по горизонтали штифтами. Совместите центральные отверстия со всеми штифтами, чтобы открыть замок.

## Механика отдельно

[`mechanics/lock-mechanics.mjs`](mechanics/lock-mechanics.mjs) — автономный ES-модуль без DOM и зависимостей. Включает генератор, движения, определение упоров, сессию, поломку и сброс. Его использует и сама игра: дублирующей реализации нет.

```js
import { createSession, attempt } from './mechanics/lock-mechanics.mjs';

let state = createSession(4, 12345, true);
const result = attempt(state, 0, -1);
state = result.state;
```

[Документация API](mechanics/README.md).

Это головоломка, а не самостоятельная защита от ботов. Для использования в дополнительной CAPTCHA нужны серверная проверка ходов, одноразовые задачи и ограничения запросов; автоматическое решение самой головоломки остаётся возможным.

## Проверки

```sh
node --test tests/engine.test.mjs
node tests/session.mjs
```

Проверяются решаемость генерации, направление связей, границы движения, поломка и сброс.

## Источники

- [Модель решателя Xetoxyc](https://github.com/Xetoxyc/gothic-remake-lockpicker)
- [Игровая механика и скриншоты](https://www.gamesradar.com/games/rpg/gothic-1-remake-lockpicking/)

Неофициальный проект, не связанный с Alkimia Interactive и THQ Nordic. Графика и аудиозаписи из игры не используются; звуки синтезируются программно. Навыки обученного взломщика и мастера не моделируются.

## Свои звуки

Положите MP3 или WAV в папку `sounds/`. Имена файлов и события описаны в [sounds/README.md](sounds/README.md). Можно заменить часть эффектов; остальные останутся встроенными.
