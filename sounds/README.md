# Свои звуки для LOX

Положите файлы в эту папку рядом с README. Код менять не нужно.

| Имя | Событие |
| --- | --- |
| `select.mp3` | Выбор пластины |
| `insert.mp3` | Вставка новой отмычки |
| `turn.mp3` | Поворот отмычки |
| `slide.mp3` | Движение пластин и щелчки штифтов |
| `impact.mp3` | Упор при отключённой поломке |
| `bend.mp3` | Отмычка погнулась |
| `snap.mp3` | Отмычка сломалась |
| `remove.mp3` | Извлечение отмычки после открытия |

Вместо `.mp3` можно использовать `.wav`. Имена — строчными буквами. При наличии обоих форматов выбирается MP3; если он не декодируется, игра пробует WAV.

Можно заменить только часть звуков. Отсутствующий, повреждённый или ещё загружающийся файл заменяется встроенным синтезированным звуком. Пользовательские записи воспроизводятся с исходной скоростью. Громкость регулируйте в самих файлах; общий переключатель «Звук» работает для всех эффектов.

Используйте короткие записи без тишины в начале. Во время хода `turn` и `slide` могут звучать вместе.

Загрузите папку вместе с сайтом. На GitHub Pages добавьте файлы в `sounds/` репозитория и дождитесь публикации. После замены обновите страницу: записи перечитываются при загрузке. На первом взаимодействии, пока аудио декодируется, возможен встроенный звук. Открывайте игру через HTTP/HTTPS, а не двойным кликом по HTML.
